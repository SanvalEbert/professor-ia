# Professor IA

Landing page da **Jornada Professor IA — Inteligência Artificial para potencializar a prática docente**.

Uma iniciativa de **Sanval Ebert**.

## Objetivo

Divulgar a jornada gratuita, apresentar sua proposta formativa e captar inscrições de professores de diferentes regiões do Brasil.

## Stack prevista

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Status

Projeto em desenvolvimento. A primeira versão será um MVP responsivo com landing page, formulário de inscrição, identificação da origem do acesso e página de confirmação.
